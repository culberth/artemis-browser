Filters use Artemis core syntax — a property by its bare name, or AMQPriority, AMQTimestamp, AMQDurable, AMQSize. JMS selector names such as JMSCorrelationID are not rejected; they simply match nothing. To look up one message, paste its ID:… (or AMQUserID = 'ID:…'): that looks for it in every state a queue can hold it in — scheduled, waiting, in flight to a consumer, or held by a prepared transaction — and reports where it could not look.

Each row is an observation: the message was in that state when that read returned. It is not a delivery history — a message can move between reads, and the reads here are made one queue and one state at a time. A message in flight or held by a transaction has no body to show; the broker returns none.

Seen more than once: a multicast address keeps a copy per subscription, and a message that moved while being looked for (scheduled, then waiting, say) is seen once in each state. The times say which came first.
