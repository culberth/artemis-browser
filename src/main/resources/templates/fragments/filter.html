Build a filter — property, priority, time sent, durability; no syntax needed

Properties

“Sent as” matters: the broker compares types strictly, so a property the sender set as the text "5" is not found by the number 5, nor true by the text 'true'. Text is matched exactly, including case. A name with a hyphen or a dot is quoted for you — left bare, order-id would be read as order minus id and match nothing.

Headers

Times are read in the zone named, which starts as this server’s (UTC) — not necessarily your browser’s. Any IANA name works (Europe/London, America/New_York, UTC). The instant each end became is shown below the filter.
